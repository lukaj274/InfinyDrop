# InfinyDrop
## What is InfinyDrop?
InfinyDrop is a multiplatform single player game in which the player is falling from the sky and is trying to avoid landing on spikes

## Is it open source?
Yes, InfinyDrop is open source and licensed under the 3-Clause BSD License.

## What platforms is InfinyDrop available on?
InfinyDrop is available on its website, https://lukaj274.github.io/InfinyDrop/.

## Controls
- 'A' and 'D' or arrow keys to move left and right
- 'Escape' or click the pause button to pause
